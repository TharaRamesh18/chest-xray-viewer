
# Chest X-ray Image Viewer

## About
A beginner-friendly biomedical engineering
project built using Python and Streamlit.

## Features
- Upload chest X-ray images
- View original images
- Convert images to grayscale
- Adjust brightness and contrast
- Download processed images

## Technologies Used
- Python
- Streamlit
- Pillow

## How to Run
Install the dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Disclaimer
This project is for educational image processing
and is not intended for medical diagnosis.
